# ssd-data

Build-time data for the `/projects/ssd` page. 

## Files

- `queries.json` — pre-recorded NL-to-SQL examples (query, generated SQL, and result summary)
- `metrics.json` — system performance and scale metrics

## Lifecycle

Since the production site is password-protected, this directory contains **snapshots** of real system behavior extracted from the `../ssd` codebase and tests.
